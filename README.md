# 听海 · Seaside Breeze 🌊

> CMIT 参赛作品 —— 一个可以自由探索的海边模拟世界。
> 第一人称漫步沙滩、潜水观鱼、驾驶小船出海，配上程序实时生成的轻松轻音乐与海浪声。

## ✨ 运行方法

**方式一（最简单）**：直接双击 `index.html`，用 Chrome / Edge 打开即可。

**方式二（本地服务器，效果相同）**：

```bash
cd seaside-explorer
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

无需安装任何依赖 —— Three.js 已内置在 `libs/` 中，完全离线可运行。

## 🎮 操作说明

| 按键 | 功能 |
| --- | --- |
| `W A S D` / 方向键 | 移动 / 驾船 |
| 鼠标 | 视角（点击画面锁定） |
| `Shift` | 疾跑 |
| `Space` | 跳跃 |
| `E` | 登上 / 离开小船（走到船边按 E） |
| `M` | 音乐开关 |
| `H` | 帮助面板 |
| `Esc` | 释放鼠标 |

## 🗺️ 探索指引

- 沙滩上有棕榈树、浮木、贝壳与草丛，海边矗立着三座海蚀柱
- 走进海里会自动切换为**游泳模式**，潜入水下可以看见成群的小鱼
- 走到小船旁按 `E` 登船，`W` 前进 `A/D` 转向，出海向西看海岬、向东寻一座小岛
- 跳进水里？潜水时画面与声音都会变得"闷闷的"，很有代入感

## 🔧 技术亮点

- **Gerstner 五重波海面**：自定义 GLSL 顶点位移 + 解析法线，JS 与着色器共用同一波浪函数，船只与玩家的浮动和海面严格同步
- **真实感水体着色**：深度渐变色（浅滩碧绿→深海军蓝）、菲涅尔天空反射、太阳高光、高频法线扰动波光、周期性涌岸碎浪与浪尖白沫
- **高度图水深查询**：地形烘焙为 GPU 纹理，水面逐像素计算水深驱动透明度与岸沫
- **程序化天空**：渐变穹顶 + fbm 噪声积云 + 太阳光斑，与水面反射共享同一函数
- **零音频文件**：Web Audio API 实时合成 —— 粉噪声海浪（双 LFO 涌动）、C 宫五声音阶随机拨弦 + 反馈延迟混响、和弦铺底、海鸥鸣叫
- **氛围细节**：棕榈叶摇曳、海鸥盘旋、鱼群巡游、船尾泡沫尾迹、潜水色调与闷音、冲刺视野拉伸
- 全部资源本地化，**离线可运行**；无外部网络请求
